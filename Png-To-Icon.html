Two jobs, one window

AIRLINK doesn't try to be a full image editor — it does the two conversions you need before shipping an app or a site, and lets you control exactly what gets generated.

TAB 1

PNG → ICO

Pick a source image, choose which resolutions to bake in, and get back a proper multi-resolution Icon.

  • 16 through 256px, selected individually
  • High-quality resampling, no blur at small sizes
  • Save target chosen from a file picker, not a fixed path
TAB 2

Favicon & PWA package

Generates the full set a modern site expects, plus the manifest and markup, zipped and ready to hand off.

  • App name, theme color, and background color set in the form
  • site.webmanifest and head-icons.html written for you
  • Per-size filenames editable before you generate
