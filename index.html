architecture

One connection to Icecast. Two sources feeding it.

SOURCE A

Playlist

Plays your media folder in order, one track at a time, at real playback speed.

SOURCE B

Microphone

Captures your system mic live — DirectShow, avfoundation, or PulseAudio, depending on your OS.

→
PERSISTENT

Encoder

Stays connected to Icecast for the whole session. Never restarted when you switch sources.

→
DESTINATION

Icecast

Your mount point stays up — no reconnect, no gap, no listener drop.

Most streaming softwares open a fresh Icecast connection every time the source changes — which is exactly the moment a listener gets kicked. AIRLINK separates the two: the encoder that talks to Icecast runs continuously, and only the small decoder process feeding it gets swapped.

what it does

Built for the switch, not just the stream.

Seamless source switching

Move between playlist and mic, or skip tracks, without the Icecast mount ever going down.

Runs quietly in the background

ffmpeg processes are launched with no visible console windows — the app stays out of your way while it works.

Configurable without editing code

Set your Icecast host, port, mount, password, playlist folder, and mic device from the Settings dialog or from the command line.

Cross-platform mic capture

Handles the input syntax differences between DirectShow (Windows), AVFoundation (macOS), and PulseAudio (Linux) automatically.

Readable failure states

If Icecast rejects the connection, you see ffmpeg's actual error in the status bar — not a silent retry loop.

before you run it

Requirements

AIRLINK is a software, not a compiled app — it drives ffmpeg for encoding and expects an Icecast server already running somewhere reachable.

  • ffmpeg installed and on your system PATH
  • Icecast a running server you have source credentials for
  • Mic (optional) any input device your OS exposes to ffmpeg
--hostIcecast server address
--portIcecast server port
--mountMount point, e.g. /stream
--passwordIcecast source password
--folderPlaylist media folder
--mic-windowsDirectShow device name
get started

Run your first broadcast

Save the software, point it at your Icecast server, and launch it. Everything else — playlist, mic switching, background processes — is handled from the GUI.

$ iCast.exe --host stream.example.com --port 8000 --mount /live --password ****** --folder ./playlist
